# App Trusted — Expo Prototype

نسخة تجريبية أولية لتطبيق App Trusted.

## التشغيل
```bash
npm install
npx expo start
```

ثم شغّلها على Android عبر Expo Go أو ابنِ APK باستخدام EAS.

## الموجود حاليًا
- Splash باسم App Trusted
- شاشة دخول المالك/التاجر
- واجهة محادثات تجريبية
- شاشة Chat وإرسال رسائل محليًا
- واجهة قابلة للتوسعة للـ OTP والـBackend

> هذه نسخة Prototype وليست نظامًا إنتاجيًا. لا توجد مصادقة حقيقية أو قاعدة بيانات أو إرسال SMS/OTP في هذه المرحلة.
