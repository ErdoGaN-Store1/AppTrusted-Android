# App Trusted Android — النسخة الأولى

هذه بداية مشروع Android مستقل باستخدام React Native + Expo، وليس APK جاهزًا بعد.

## ما الموجود الآن
- إعداد مشروع Expo Android.
- شاشة تسجيل دخول مربوطة بمشروع Supabase الحالي عبر المفتاح العام publishable.
- شاشة أولية للجروب تحاول قراءة/إرسال الرسائل من `group_messages` باستخدام `room_key = orders` وحقول `sender_id`, `body`, `created_at`.
- واجهة داكنة بنفسجية مخصصة للموبايل.

## قبل البناء
1. ثبّت Node.js LTS على كمبيوتر.
2. فك ضغط المشروع وافتح Terminal داخل المجلد.
3. شغّل `npm install` ثم `npx expo start`.
4. اختبر تسجيل الدخول والشات بحساب تجريبي.
5. لو ظهر خطأ في جدول الرسائل، لا تنشئ جدولًا جديدًا مباشرة؛ راجع أسماء الأعمدة والسياسات الحالية في Supabase أولًا.

## استخراج APK
بعد اختبار المشروع، ثبّت EAS CLI وسجّل الدخول إلى Expo، ثم نفّذ `eas build:configure` واضبط `app.json` وملف البناء، وبعدها اطلب Android APK من EAS Build. يتطلب ذلك حساب Expo واتصال إنترنت.

## أمان
المفتاح الموجود هو publishable key مخصص للواجهة. لا تضع أبدًا `service_role` أو مفاتيح سرية داخل تطبيق الموبايل. حماية الجداول يجب أن تعتمد على RLS وسياسات Supabase.

## إخراج APK من الموبايل فقط عبر GitHub Actions

1. أنشئ مستودع GitHub جديدًا باسم `AppTrusted-Android` واجعله Private أو Public حسب رغبتك. لا ترفع ملفات التطبيق داخل مستودع الموقع الحالي حتى لا تختلط ملفات الموقع بالتطبيق.
2. ارفع محتويات هذا المجلد إلى جذر المستودع الجديد، بما فيها مجلد `.github/workflows` وملف `eas.json`.
3. افتح https://expo.dev وسجّل الدخول، ثم أنشئ مشروع Expo جديدًا أو سجّل الدخول بالحساب الذي ستستخدمه للبناء.
4. أنشئ Access Token من إعدادات حساب Expo، ثم في GitHub افتح المستودع: Settings → Secrets and variables → Actions → New repository secret. الاسم `EXPO_TOKEN` والقيمة هي التوكن. لا ترسله في المحادثة ولا تضعه داخل ملفات المشروع.
5. في GitHub افتح Actions → Build App Trusted Android APK → Run workflow. سيربط سير العمل مشروع EAS ثم يبدأ البناء؛ إذا ظهرت رسالة تطلب إعداد المشروع أو صلاحية، أرسل نص الخطأ.
6. تابع سجل التشغيل. بعد نجاح EAS، افتح رابط البناء الذي يظهر في السجل/Expo، ثم نزّل ملف APK على هاتفك وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

مهم: هذا المسار يجهّز عملية بناء سحابية، لكنه لا يعني أن APK بُني أو أن التطبيق اختُبر. يجب معالجة أي خطأ يظهر في Actions/EAS. كما أن توافق الشات مع مخطط جداول وسياسات Supabase الحالية ما زال يحتاج اختبارًا فعليًا قبل الاعتماد عليه.
